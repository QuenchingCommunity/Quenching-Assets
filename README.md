# Quenching Assets · 淬火 MOD 资源

Warcraft III 淬火 MOD 的模型、纹理、地形、着色器等资源维护仓库。

[完整资源包与更新 / Releases](https://github.com/QuenchingCommunity/Quenching-Assets/releases/latest) · [客户端](https://github.com/QuenchingCommunity/Quenching-Client/releases/latest) · [安装手册](https://github.com/QuenchingCommunity/Quenching-Gitbook) · [社区](https://qm.txzy.net/)

## 下载与使用 / Downloads

玩家请从 **Releases** 下载发布包。GitHub 的 `Download ZIP` 是仓库源码快照，不是面向玩家整理的安装包。

首次安装请按 Release 说明下载完整包 **A 和 B**，解压到同一资源目录或在客户端同时选择两个包。两者是普通 ZIP，完整安装需要两份。更新包的适用起始版本与安装方式以对应 Release 为准。

客户端和 MOD 资源版本独立。维护分支中的改动也不等于已发布版本；资源维护与正式发布说明见 [MAINTENANCE.md](MAINTENANCE.md)。

Players should download release packages rather than the repository snapshot. Both full-package A/B ZIPs are needed for a complete installation. Follow the release instructions for update compatibility. The client is a separate download.

# Quenching-Assets

This is the assets package of quenching mod, quenching mod must be running with these assets.

You can use these assets in your own project freely, as long as you credit the [Quenching Mod] or [天下正义].

This working tree was initialized from QMF3.5 on 2026-10-04. It is the current
resource maintenance tree; its changes are not automatically published as a release.

See [MAINTENANCE.md](MAINTENANCE.md) for the source directories, client asset
mapping, and release preparation notes.
